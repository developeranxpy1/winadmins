Enable the built-in Windows Administrator in one line. Default login Administrator / 731235, a sign-in tile, and a one-command undo - without digging through menus.

Download .ps1

Press Win + R, paste, and hit Enter.

One-liner

Open Run. Paste. Done.

The command fetches the latest script and runs it in memory. It asks for Administrator rights, then handles the rest on its own.

Run
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://winadmins.vercel.app/ | iex"

  3. 3
    Approve the UAC promptApprove it, then press Enter in the script window to choose [1] Enable.

What you get

Small script. Real admin access.

Automatic UAC elevation

One prompt, then the script reopens itself with the rights it needs - even when piped straight from the web.

Default credentials

Sign in as Administrator with password 731235. Change it after your first sign-in.

Sign-in visibility

Adds the account to the Windows sign-in screen and enables local account listing, so it is easy to find.

One-command undo

A small state file in ProgramData lets the same one-liner restore the original settings when you choose [2].

Undo / uninstall

Changed your mind? Same command.

Run the one-liner again and choose [2] Undo everything.

  • The account is restored to its previous state (disabled on a standard install).
  • The sign-in visibility entries are restored to their original values.
  • The saved state file is deleted.
  • The default login stays on the account (Administrator / 731235). Change the password after your first sign-in. Run Disable-LocalUser -Name Administrator if you want it disabled even when it was enabled before.
What gets changed

Exactly three things.

  • The built-in Administrator account gets the default password 731235 and is enabled.
  • SpecialAccounts\UserList is set so the account appears on the sign-in screen.
  • EnumerateLocalUsers is enabled so local accounts are listed.

A snapshot is saved to C:\ProgramData\WINADMINS\state.json before anything changes.

Complete uninstall

Undo everything. Leave nothing behind.

WINADMINS installs no program, service, startup entry, or scheduled task. The undo option reverses every change and deletes its saved state.

  1. 1
    Run the one-liner againOpen Run or PowerShell and use the same command from the top of this page.
  2. 2
    Choose [2] Undo everythingThe account returns to its original state (disabled on a standard install), both registry values are restored, and the state file is deleted.
  3. 3
    Sign out or rebootThe Administrator tile disappears from the sign-in screen.
  4. 4
    Remove local copiesDelete any downloaded winadmins.ps1 and clear the clipboard if it still holds the password.
Verify

Check that it is gone.

PowerShell 
Get-LocalUser -Name Administrator | Select-Object Name, Enabled
Test-Path C:\ProgramData\WINADMINS

Expected on a standard install: Enabled False and False. If the account was enabled before WINADMINS, undo restores that state; use Disable-LocalUser -Name Administrator to force it off.

  • The built-in Administrator cannot be deleted by Windows; it is disabled instead.
  • The default login remains on the account (Administrator / 731235). Change the password after your first sign-in.
  • No program, service, or scheduled task is left behind.

FAQ

Good questions.

Do I need to download the script?+
No. The one-liner downloads the latest version and runs it in memory. Download it only if you want to inspect it or keep a local copy.
Why does it ask for Administrator rights?+
Enabling the built-in account and changing its sign-in visibility require Administrator rights. Windows will show a normal UAC prompt before anything happens.
What are the default login details?+
The default username is Administrator and the default password is 731235. The script shows both and copies the password to your clipboard. Change it after your first sign-in; it is the same on every install. On localized Windows, the built-in account may have a different display name.
How do I undo everything?+
Run the same one-liner and choose [2] Undo everything / uninstall. The account is restored to its previous state (disabled on a standard install), the registry changes are restored, and the saved state is deleted. The account keeps its default password (731235); its username is Administrator.
Why is the Administrator tile not on the lock screen?+
Sign out or reboot first. On some builds, choose Other user at the sign-in screen and sign in as Administrator (or .\Administrator; the display name may be localized). The account is enabled even if the tile is not shown.
Is this safe?+
The script makes exactly the changes listed above and keeps a state snapshot for undo. That said, enabling the built-in Administrator is a real security change. Use it on a PC you own or manage, change the default password immediately after first sign-in, keep the new password private, and undo when you are done.
Where is the source code?+
Everything lives on GitHub at developeranxpy1/winadmins under the MIT license - the installer, the bootstrap, and this page.
The command opens the website or errors out.+
Use the raw fallback: irm 'https://winadmins.vercel.app/?raw=1' | iex. It forces the installer response even if your network changes the PowerShell user-agent.
Windows blocked the downloaded file.+
The script is unsigned, so SmartScreen may warn. The one-liner runs in memory and does not write a file. If you downloaded it, right-click the file, open Properties, tick Unblock, and apply.
Use it on a PC you own or manage. Enabling the built-in Administrator is a real security change. The default login (Administrator / 731235) is public, so change the password after your first sign-in, keep it private, and undo the change when you no longer need it.
